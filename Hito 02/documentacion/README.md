El sistema es una aplicación web para automatizar la gestión de reserva de espacios de trabajo.

Pantallas desarrolladas:
-Principal: pagina de inicio
-Membresías: página con información acerca de los planes de suscripción de servicios
-Contacto: página de comunicación con la empresa
-Historial: página de consulta de los usuarios con respecto de sus reservas pasadas, futuras y presentes
-Espacios: página de presentación de los espacios de trabajo

Funcionalidades para la próxima entrega:
-Página de reserva de espacios
-Página de log in
